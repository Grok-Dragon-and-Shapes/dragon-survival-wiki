# dragon-survival-wiki

Справочник мобов и руд из мода Dragon Survival. Открой `index.html` в браузере.

## Как добавить запись

Добавь объект в массив `ENTRIES` в `app.js`: `name`, `kind` (моб или руда), `biome`, `note` и `source` со ссылкой на источник из списка `SOURCES`.

## Статус

Страница выложена без записей. Записи появятся после проверки по источникам.
